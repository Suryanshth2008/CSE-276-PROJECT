// --- L298N Skid-Steer Firmware with 600ms Watchdog ---
const int IN1 = 8, IN2 = 9;   // Left Motors
const int IN3 = 10, IN4 = 11; // Right Motors
const int ENA = 5, ENB = 6;   // PWM Speed

unsigned long lastTime = 0;
const unsigned long TIMEOUT = 600; // Auto-stop watchdog

void setup() {
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
  pinMode(ENA, OUTPUT); pinMode(ENB, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  if (Serial.available()) {
    char cmd = Serial.read();
    lastTime = millis();
    if (cmd == 'F') moveForward();
    else if (cmd == 'L') turnLeft();
    else if (cmd == 'R') turnRight();
    else stopMotors();
  }
  // Safety watchdog stop if packets halt
  if (millis() - lastTime > TIMEOUT) stopMotors();
}

void moveForward() {
  analogWrite(ENA, 180); analogWrite(ENB, 180);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void turnLeft() {
  analogWrite(ENA, 160); analogWrite(ENB, 160);
  digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void turnRight() {
  analogWrite(ENA, 160); analogWrite(ENB, 160);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH);
}

void stopMotors() {
  analogWrite(ENA, 0); analogWrite(ENB, 0);
  digitalWrite(IN1, LOW); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, LOW);
}

Module 7: System Architecture & Technical FAQs

Design principles, algorithmic derivations, and searchable technical questions & answers.

🔍
RGB couples chromaticity and luminance across all three channels. When clouds pass or tree shadows fall, R, G, and B all drop drastically, breaking thresholding. In HSV, Hue and Saturation isolate pure colour from brightness, while CIE LAB isolates perceptual luminance in the L-channel so CLAHE can normalize harsh tree shadows without distorting trail colour.
While maintaining 73.0% path detection consistency on shadowed gravel trails, adding LAB CLAHE shadow compensation and lookahead heading fusion reduced cross-track RMSE from 0.5400 to 0.5102 (-5.6% error reduction) and achieved 83.0 FPS average processing speed on a standard CPU.
A ground rover must follow the terrain directly touching its front wheels. If we only selected the largest contour by area, a distant clearing or background tree opening with similar colour could hijack the steering. Anchoring to the lowest 20% of the ROI ensures continuous contiguous path following.
The ±0.08 deadband establishes a neutral zone around zero error to prevent high-frequency LEFT/RIGHT motor chattering on straight paths. The 5-frame grace period in PATH_UNCERTAIN holds the last safe steering angle during momentary shadow flicker before safely triggering STOP_NO_PATH if the trail is truly lost.
Using spatial image moments via cv2.moments(): M00 represents the total segmented pixel area, while M10 and M01 represent the weighted pixel coordinate sums along the X and Y axes. The centroid is obtained through cx = M10 / M00 and cy = M01 / M00.
During extreme switchback hairpin bends, the trail curves beyond the monocular camera's horizontal field of view in the lower 58% ROI. Because open-loop benchmark video playback cannot steer the camera back onto the trail, the path temporarily exits the frame, triggering NO_CANDIDATE_PIXELS and a safe STOP_NO_PATH transition.
Python writes 1-byte ASCII characters ('F', 'L', 'R', 'S') via USB Serial at 9600 baud to an onboard Arduino Uno. The Arduino reads the character and sets the digital logic (IN1–IN4) and PWM pins (ENA, ENB) of an L298N Dual H-Bridge to drive 4 DC geared motors. A 600ms watchdog timer auto-stops the rover if serial packets halt.
Limitations: 2D colour-only segmentation cannot detect 3D positive obstacles (like brown logs) sharing path colour. Safety mitigations: Autonomous failsafe stops when confidence < 0.30, physical watchdog timers, local edge computation without storing facial video for privacy, and strict commitment to non-weaponized search/rescue and agricultural robotics.
